GranuWarm: Step-by-Step Learning & Implementation
Roadmap
A Phase-by-Phase Mastery Guide for CSE Research Students
Welcome to the official step-by-step learning and implementation roadmap for GranuWarm! This guide
breaks down the full system into 15 manageable, self-contained phases (Phase 0 through Phase 14).
Rule of Engagement: Complete and verify one phase at a time. Do not attempt to write code for
future phases until the current phase's verification criteria are fully met.
PHASE 0 — Prerequisites
1. What You Need to Learn
Linux Command Line Interface (Bash/Zsh navigation, process management, environment variables).
Python 3.11 core fundamentals (asyncio, type hinting, package management via pip, virtual
environments via venv).
Version control with Git (git init, git commit, .gitignore management).
Basic computer systems concepts (CPU, RAM, process threads, HTTP/REST basics).
2. Why You Need It
GranuWarm is an asynchronous Python application that controls containerized Linux workloads. A solid
foundation in Linux, Python 3.11, and Git prevents environment issues later.
3. Exact Practical Task
1. Set up an Ubuntu 22.04 LTS development environment (native, dual-boot, or VM with at least 8 CPU
cores and 16 GB RAM).
2. Install base system utilities:
sudo apt update && sudo apt install -y curl git htop jq build-essential 
python3-pip python3-venv
3. Initialize the GranuWarm Git repository and create a clean Python 3.11 virtual environment:
mkdir granuwarm && cd granuwarm
git init
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
